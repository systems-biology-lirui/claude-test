# 非机动车道行人动能测试 · 像素版
**THE PEDESTRIAN KINETIC ENERGY TEST — PIXEL EDITION**

竖屏 1080×1920 · 30 fps · 31.0 秒（930 帧）· H.264 + AAC · 中文字幕直接画进画面

> 本文档已更新为**最终成片版本**，和 `src/timeline.py`、`src/physics.py` 中的实际数值一致。

> 本片为虚构像素动画，所有数值只用于动画演示，不代表任何人体伤害阈值。
> 画面里没有血液、伤口或写实受伤，受击反馈全部是街机式的夸张表现：击退、转圈、眩晕、掉手机、手机碎屏、警报、屏幕震动、屏幕裂纹。

## 2. 画面风格说明

- **分辨率策略**：在 270×480 的低分辨率画布上逐帧绘制，最后用"最近邻"整数放大 4 倍到 1080×1920。每个像素都是严格的 4×4 方块，边缘绝对锐利。因为像素块对齐到 4 的倍数，H.264 的 4:2:0 色度采样也不会让颜色边缘发糊。
- **视角**：街机清版动作游戏式的侧面斜俯视。街道分层横向排列：远处楼房 → 人行道 → 路缘 → 非机动车道 → 机动车道。物体从左往右沿车道运动，轨迹和接触点完全可见。竖屏的上下空间用于开场下摇和第 5 关的升空上摇。
- **时间与光线**：黄昏刚亮灯。天空从深靛蓝渐变到紫、品红、橙，用像素抖动过渡。楼房窗户亮暖光，路灯在地面投下暖色光斑，行人的脸被手机屏幕照成冷青色（"被手机照亮的人"）。
- **调色板**（约 120 色的自定义调色板，按功能分组）：
  - 夜空：深靛蓝、紫、品红
  - 夕阳：橙、暖黄
  - 车道：柏油灰紫
  - 非机动车道：绿色
  - 标志：蓝色
  - HUD：安全黄、警示红、白、深海军蓝底板
  - 行人：橙色卫衣（和绿色车道、紫色天空互补，保证他永远是视觉焦点）、蓝色牛仔裤、白色大耳机
- **场景细节**：
  - 人行道：空无一人，带黄色盲道
  - 街边：行道树、路灯、蓝色非机动车道标志牌
  - 车道：路面上的自行车图标和箭头
  - 店铺：便利店、奶茶店、修车铺，招牌以图标为主，避免抢 HUD 的文字
- **动态细节**（避免"幻灯片感"）：
  - 行人：随音乐点头，刷手机时屏幕光闪烁，耳机里持续飘出音符
  - 环境：霓虹招牌闪烁、天线红灯闪、窗户偶尔开关灯
  - 所有运动都按物理和缓动曲线来，没有匀速漂浮
- **受击表现**（全部是非写实的街机语言）：
  - 时间：顿帧（hit-stop）、慢动作
  - 闪光与冲击：白闪、反色闪、像素冲击星爆、冲击波环
  - 动作与粒子：残影拖尾、速度线、尘土粒子、击退、"纸片式"转身、头顶转星星、像球瓶一样倒下
  - 道具与镜头：手机飞出、手机碎屏、屏幕裂纹、警示灯、警报条、屏幕震动
- **字体**：中文和英文都用方舟像素字体（Ark Pixel Font，12px 点阵，SIL OFL 开源授权），大标题由同一字体整数放大，加粗、描边、加投影、加渐变。不用难以辨认的艺术字，所有文字都由程序渲染，不会乱码。

## 4. 配乐和音效方案

全部用代码原创合成，不使用任何外部音频素材。模仿 8-bit 游戏机的音色结构，再加一层现代的低频，让撞击更有分量。

**配乐声部**

| 声部 | 用途 |
|---|---|
| 方波 1 | 主旋律 |
| 方波 2（窄占空比） | 琶音 |
| 三角波 | 贝斯 |
| 噪声 | 鼓组：底鼓、军鼓、踩镲 |
| 正弦超低音 | 只在撞击时出现 |

**段落设计**

| 时间 | 段落 | 内容 |
|---|---|---|
| 0–4 秒 | 开场 | A 小调，120 BPM，冷静的"实验室/科普节目"主题，只有三角波贝斯和轻琶音 |
| 4–16 秒 | 第 1–3 关 | 鼓组进入，配器一关比一关厚。每关开头有一段上行的"关卡音效"，音高逐关升高 |
| 16 秒起 | 第 4–5 关 | 提速到 150 BPM 并升调（类似游戏里"时间快到了"的加速），踩镲变成 16 分音符 |
| 19.2 秒 | 第 5 关警报 | 双音警报接管音乐 |
| 22.4 秒 | 第 5 关撞击 | 音乐在撞击帧被硬切断，进入静默 |
| 26 秒 | 结尾 | 一段短小的收尾旋律 |

**撞击音效**（每关明显不同，低频逐级加重）

| 关卡 | 撞击音效 |
|---|---|
| L1 | 高频短促"啵"，几乎没有低频 |
| L2 | 中频"嘭"加少量噪声 |
| L3 | 音高下滑的"砰"加 60 Hz 低频，慢动作阶段有拉长的风声 |
| L4 | 低频滚动隆隆声，接一组球瓶碰撞的咔嗒声和噪声爆裂，再接"STRIKE!"小号式音效 |
| L5 | 电机嗡鸣和车铃之后，是 40 Hz 超低频冲击、比特粉碎噪声、碎玻璃声，再加警报回声 |

**其他音效**

| 类别 | 音效 |
|---|---|
| 界面 | 打字"嘀嘀"、数值滚动的连续 tick、横幅砸入、锁定"哔哔" |
| 动作 | 呼啸（扫频噪声）、眩晕"啾啾"、手机掉落、碎屏"咔"、星光"叮"、下落哨音、落地"咚" |
| 氛围 | 耳机漏音（非常小声的芯片旋律） |

**混音**：

- 48 kHz 立体声，WAV 独立音轨另行导出。
- 撞击瞬间对音乐做侧链压缩，压低幅度逐关加深：-3、-6、-10、-11 dB。
- 母带用真峰值限幅（4 倍过采样估算）。
- 成片实测：整体响度 -16.2 LUFS，AAC 编码后真峰值 -1.6 dBTP。
- 撞击低频能量逐关递增（300 ms 窗口、<120 Hz）：-20.3 / -18.5 / -11.5 / -10.7 / -6.3 dB。

## 5. 最终完整制作方案

**技术栈**（云端容器，无 GPU、无 Blender）

| 工具 | 用途 |
|---|---|
| Python 3 + numpy + Pillow | 逐帧绘制画面、合成音频 |
| FFmpeg（libx264 / AAC） | 编码和合成 |
| 方舟像素字体 12px 字形 | 直接读取官方仓库里的逐字点阵 PNG（OFL 1.1） |

**代码结构**

| 文件 | 内容 |
|---|---|
| `src/palette.py` | 调色板 |
| `src/font.py` | 像素字体加载、排版、描边、投影、大字 |
| `src/sprites.py` | 所有像素精灵（ASCII 点阵绘制）：行人正面和背面、受击姿势、手机（完好/碎屏）、四种球、电动车和骑手、图标 |
| `src/scene.py` | 背景生成：天空、天际线、楼房、店铺、人行道、车道、路灯光斑 |
| `src/fx.py` | 粒子、冲击星爆、冲击波、残影、屏幕震动、裂纹、扫描线、闪光 |
| `src/timeline.py` | 统一时间轴：节拍表、每关事件时间、世界时间重映射（顿帧/慢动作） |
| `src/physics.py` | 动能计算、弹跳、抛物线、缓动 |
| `src/hud.py` | 全部 HUD 组件 |
| `src/render.py` | 逐帧渲染：270×480 → 放大 4 倍 → 通过管道直接送进 FFmpeg |
| `src/audio.py` | 音乐序列器 + 音效合成 + 混音 |
| `build.sh` | 一键构建：音频 → 视频 → 合成 → 抽关键帧 |

**制作阶段**

1. 方案（本文档）
2. 场景与角色：搭调色板、字体和精灵，渲染静帧检查比例、构图、配色、文字清晰度
3. 动画：逐关实现，检查轨迹、撞击帧、顿帧、反应动作、HUD 时序
4. 声音：按时间轴合成音乐和音效，撞击和小节第一拍逐帧对齐
5. 自查：抽每关关键帧和接触帧，检查以下几项后修复
   - 穿模、碰撞是否自然
   - 角色一致性
   - 文字错别字和溢出
   - 节奏
6. 最终渲染：1080×1920，30 fps，H.264 High（CRF 10，yuv420p，BT.709）+ AAC-LC 256k

**平台安全区**：顶部卡片、动能大字、结尾文字都避开了抖音、TikTok 的顶部标签栏、右侧按钮列和底部文案区。
