# 素材与字体说明

## 字体

| 用途 | 字体 | 作者 | 授权 |
|---|---|---|---|
| 全片中文和英文文字（12px 和 10px 点阵） | 方舟像素字体 Ark Pixel Font | TakWolf | SIL Open Font License 1.1 |

- **来源**：[TakWolf/ark-pixel-font](https://github.com/TakWolf/ark-pixel-font) 仓库中的逐字点阵字形源文件 `assets/glyphs/{12,10}/cmap/…/XXXX.png`，中文优先使用 `zh_hans` 变体。
- **打包内容**：`assets/ark_pixel_glyphs/` 只收录片中和封面实际用到的字形（约 240 个 PNG），授权原文见 `assets/ARK_PIXEL_FONT_LICENSE-OFL.txt`。OFL 允许在视频中使用，也允许随项目再分发字形，但须保留授权文本。
- **大字的做法**：标题、关卡横幅、结论都用同一套点阵字形整数倍放大（2×、3×、4×），再由代码加粗、描边、加投影和渐变，没有使用其他艺术字体。
- **自绘图标**：勾号 ✓、警告三角 ⚠、星形 ★ 在字体中没有对应字形，按 12px 网格手绘，见 `src/font.py` 中的 `CUSTOM12`。
- **缺字处理**：12px 字库恰好没有「然」字，所以文案改成「仍在非机动车道」；也没有「≈」，改成「约」。渲染前程序会逐字检查字库覆盖，有缺字就直接报错，不会出现豆腐块或乱码。

## 图像

**全部原创，由代码生成**，没有使用任何外部图片、贴图或素材包。

- **角色和物体精灵**：行人、电动车和骑手、汽车、乒乓球、网球、足球、保龄球、手机（含碎屏版）、音符、星星，都在 `src/sprites_ped.py` 和 `src/sprites_obj.py` 里用 ASCII 点阵逐像素绘制。
- **场景**：天空渐变、星星、月亮、远景天际线、楼房、店铺、行道树、路灯、标志牌、人行道、盲道、车道标线等，都是 `src/scene.py` 中带固定随机种子的程序化生成，每次重建结果完全一致。
- **特效**：冲击星爆、冲击波、粒子、扬尘、碎屏裂纹、闪白、反色、扫描线，见 `src/fx.py`。
- **虚构信息**：店招只用通用名称（便利店、奶茶、修车）。「PIXEL TRAFFIC LAB」是虚构的实验室名称，不指向任何真实机构、品牌或人物。

## 声音

**全部原创，由代码合成**，没有使用任何外部音频、采样或音色库。

- **配乐**：模仿 8-bit 游戏机的声部结构，包括两路方波、4-bit 三角波贝斯、LFSR 噪声鼓组，再加一层只在撞击时出现的正弦超低频。旋律、和声与节奏都是原创编写，见 `src/audio.py`。
- **音效**：全部由振荡器、噪声和滤波器实时合成，包括撞击声、呼啸、车铃、电机、碎玻璃、下落哨音、星光、界面提示音等。

## 工具

Python 3.13、numpy、Pillow、scipy（音频滤波）、FFmpeg 6.1（libx264、AAC）。
